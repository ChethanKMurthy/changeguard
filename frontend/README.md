# ChangeGuard web app

Next.js 16 (App Router, Cache Components) with React 19, Tailwind CSS 4 and
Motion. It renders the guided experience, the analysis workspace, reports, the
evaluation and the method pages, and proxies the engine's API on its own origin.

```bash
npm ci
CHANGEGUARD_API_URL=http://127.0.0.1:8000 npm run dev   # expects the engine on :8000
npm test               # Vitest + Testing Library
npm run test:e2e       # Playwright (run `npm run build` first; starts an engine itself)
npm run lint && npm run typecheck
```

| Path | |
|------|---|
| `src/app/` | Routes, including `api/v1/[...path]` (the same-origin engine proxy) |
| `src/proxy.ts` | Issues each browser's workspace cookie |
| `src/components/experience/` | Figures of the guided experience |
| `src/components/report/` | Report views: findings, evidence, diff, symbols, pipeline, AI trace |
| `src/data/` | Generated by the engine (`make data`, `make eval`); do not edit by hand |
| `src/lib/api/` | Typed client; `schema.d.ts` is generated from `openapi.json` (`npm run gen:api`) |

Environment: `CHANGEGUARD_API_URL`, `CHANGEGUARD_API_KEY` (server-side only),
`CHANGEGUARD_WORKSPACES` (`shared` to let everyone see every report). Design
principles are in [`../DESIGN.md`](../DESIGN.md).
